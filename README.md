# The Reversibility Canvas

Research website and browser-based Decision Studio by Qinlei Wang.

## Run locally

Serve this directory with `python -m http.server 8000` and open http://localhost:8000.

Run rule checks with `node studio/tests.js`.

## Publish

In Settings → Pages, choose Deploy from a branch, select main and / (root), then Save. The expected address is https://alyviaw.github.io/reversibility-lab/ after deployment succeeds.

## Research structure

Decision → Critical Assumption → Reversibility Profile → Evidence Threshold → Exit Trigger.

The separate Commitment Readiness Assessment uses candidate dimensions and illustrative weights. Empirical calibration and founder effectiveness evaluation remain research tasks. The studio runs locally in the browser and supports manual evidence entry, comparisons and report exports. Full company database integration and automated document extraction remain planned work.
